# 🎬 Netflix Frontend Clone

A simple **Netflix-inspired frontend** built using **HTML and CSS**. This project focuses on recreating the visual layout and user interface of a streaming platform.

## ✨ Features

- Netflix-style homepage
- Responsive layout
- Movie/show sections
- Navigation bar
- Hero/banner section
- Movie cards and thumbnails
- Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
